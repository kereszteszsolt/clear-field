What is ClearField?

ClearField is an independent, fan-made take on the classic Minesweeper puzzle. It is designed to provide a simpler, friendlier, mobile-ready experience using plain HTML, Vanilla JavaScript, and Vanilla CSS.

This project is not affiliated with any original game publisher. It does not save game results and uses no analytics or AI libraries.
